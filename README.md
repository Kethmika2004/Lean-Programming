## 📖 About

Welcome to my **Lean Programming** repository!

This repository documents my journey of learning **Lean 4**, a modern functional programming language and interactive theorem prover developed for formal mathematics, software verification, and theorem proving.

Here, I practice writing proofs, explore logical reasoning, and build a strong foundation in formal methods while improving my functional programming skills.

This repository is continuously updated as I learn new concepts and solve more challenging problems.

## 💡 Why Lean?

Lean is more than a programming language.

It combines **functional programming**, **formal mathematics**, and **interactive theorem proving** into a single ecosystem, enabling developers and researchers to create software and mathematical proofs with machine-verified correctness.

Learning Lean helps me:

- 🧠 Think more logically
- ⚡ Improve problem-solving skills
- 📖 Understand formal mathematics
- 🔍 Explore software correctness
- 🚀 Prepare for advanced Computer Science research
